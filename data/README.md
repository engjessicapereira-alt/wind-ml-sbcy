# Data

This repository does not redistribute the raw datasets used in the study.

The analyses were based on:

- hourly wind observations from Marechal Rondon International Airport (SBCY);
- meteorological observations from the Instituto de Controle do Espaço Aéreo (ICEA);
- data from the National Centers for Environmental Information (NCEI);
- ERA5 atmospheric reanalysis;
- ERA5-Land reanalysis.

The main wind-speed series covers the period from 1991 to 2020.

Raw and processed datasets are not included in this repository because of file size and possible redistribution restrictions. The code is organized so that the analyses can be reproduced after the required datasets are obtained and placed in the appropriate local directories.
