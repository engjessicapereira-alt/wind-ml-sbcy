# Data

This directory is reserved for the datasets required to reproduce the analyses.

The study uses:

- hourly wind observations from Marechal Rondon International Airport (SBCY);
- meteorological observations from the Instituto de Controle do Espaço Aéreo (ICEA);
- data from the National Centers for Environmental Information (NCEI);
- ERA5 atmospheric reanalysis;
- ERA5-Land reanalysis.

The main wind-speed series covers the period from 1991 to 2020.

Raw and processed datasets are not redistributed in this repository because of file size and possible redistribution restrictions. Users should obtain the required datasets from their original sources and place them in this directory before running the analyses.
